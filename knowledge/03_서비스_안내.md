# AI 통학버스 미하차 교차검증 서비스 안내
출처: 서비스 설명서 (팀 작성)

## 서비스가 하는 일
한 번의 운행에서 승차 사진과 종점 사진 두 장을 비교한다. 승차 인원은 승차 사진과 앱 기록으로, 종점 잔류 인원은 종점 실내 사진에서 AI(YOLO)가 센다. 종점에 사람이 남아 있으면 경고를 보내고 기록을 남긴다.

## 경고 단계
긴급(미하차 의심): 종점 사진에서 사람이 확실하게 감지된 경우. 관리자와 그 버스에 탄 아이의 보호자에게 알림이 간다.
확인 필요: 검출 신뢰도가 낮거나 사진이 어두워 AI가 확실히 판단하지 못한 경우. 관리자(기사)에게만 알리고 재촬영이나 직접 확인을 요청한다. 보호자에게는 알리지 않는다.
하차 확인 완료: 종점 사진에서 사람이 감지되지 않은 경우. 그래도 기사의 직접 확인('안전 확인 완료')이 있어야 운행이 끝난다.

## 경고 처리 흐름
경고는 열림(OPEN) → 확인(ACKED) → 해결(RESOLVED) 순서로 처리된다. 관리자가 확인을 누르면 '확인 중', 차량 내부 확인 후 해결을 누르면 '해결'이 된다. 해결할 때 조치 메모를 남긴다.

## AI 요약이란
경고가 생기면 AI가 감지 위치와 확인할 곳을 한두 문장으로 요약한다. 인원 수는 판정 로직이 정한 값을 그대로 쓰고, AI는 숫자를 바꾸지 않는다. 요약은 참고용이며 판단은 사람이 직접 확인해서 한다.

## AI가 놓치기 쉬운 경우
1. 머리가 보이지 않게 엎드리거나 누운 경우, 담요를 덮은 경우
2. 실내가 아주 어두운 경우
3. 좌석 등받이에 대부분 가려진 경우
그래서 종점마다 기사의 직접 확인을 필수로 하고, 신뢰도가 낮은 검출이나 어두운 사진은 '확인 필요'로 처리한다.

## AI가 잘못 셀 수 있는 경우
창밖에 서 있는 사람을 승객으로 세거나, 다른 차량의 좌석 모양을 사람으로 착각할 수 있다. 이 경우 기사가 확인 후 경고를 해결하고 메모에 원인을 남긴다.

## 사진과 개인정보
촬영한 실내 사진은 경고 확인을 위해서만 쓰고 일정 기간(기본 7일)이 지나면 볼 수 없다. AI 요약과 챗봇은 사진을 기본으로 외부 서비스에 보내지 않고, 감지 위치와 인원 같은 숫자 정보만 보낸다.
